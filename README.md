# SberDataHack

Проект по анализу арктических муниципалитетов России с акцентом на миграцию, потребление, инфраструктуру и рыночную доступность.

В работе собираются и сводятся данные из нескольких источников, после чего проверяются гипотезы о том, какие факторы связаны с различиями в миграционной динамике арктических поселений.

## Что внутри

- `main.ipynb` — основной ноутбук с логикой анализа и проверкой гипотез
- `master_table.ipynb` — сборка и подготовка итоговой таблицы
- `work.ipynb` — черновой анализ и просмотр исходных данных
- `.csv / .xlsx` файлы — подготовленные таблицы и промежуточные результаты

## Что анализируется

В проекте рассматриваются, в частности:

- миграционный баланс поселений
- рыночная доступность
- потребительская активность
- демографические и типологические различия между муниципалитетами

## Стек

Python, pandas, numpy, matplotlib, seaborn, openpyxl

## Запуск

Открой ноутбуки `main.ipynb` или `master_table.ipynb` в Jupyter Notebook / JupyterLab и проверь, что нужные исходные данные лежат в ожидаемых папках проекта.

## Примечание

Часть данных и путей в ноутбуках завязана на локальную структуру папок, поэтому для корректного запуска может потребоваться поправить пути к файлам.
